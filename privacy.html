Privacy Policy

Last updated: October 30, 2026

TikTok Control Center is a locally hosted application for organizing TikTok account references, LIVE links, saved message drafts and activity records. This policy describes the current local application and the planned TikTok Login Kit integration.

Information processed

The application stores TikTok usernames entered by the operator, optional account labels, LIVE URLs, message drafts, reminder preferences and local activity logs in a SQLite database on the operator's computer. It uses an administrator login session to restrict access to its dashboard.

TikTok authorization

The current application does not yet connect to TikTok through Login Kit. If official TikTok authorization is implemented, the application will request only the permissions shown during TikTok consent, initially basic profile information. This policy will be updated before any additional TikTok data or tokens are processed.

Purpose and sharing

Information is used to organize accounts and local dashboard settings. The current application does not automatically publish comments, likes or shares on TikTok. Local records are not intentionally sold or shared with advertisers. Opening TikTok links is subject to TikTok's own privacy practices.

Storage and retention

Local records remain on the operator's device until deleted from the dashboard or its local database. Dashboard deletion removes the selected account and associated saved preferences and activity records. Local backups, if made by the operator, must be deleted separately.

Security

The application is intended for local access on 127.0.0.1. The operator is responsible for safeguarding the device, administrator password and any backups. Do not upload local configuration, credentials or databases to a public repository.

Your choices and requests

The operator can remove locally stored accounts in the dashboard. For questions about privacy or deletion requests, contact the application operator through the contact information published with the application. A direct contact address must be added before submitting this policy for public app review.

Changes

This policy will be revised if the application gains official TikTok authorization, remote hosting, new integrations or additional data processing.
